# 08 查核紀錄（冷咖啡、現代特調、咖啡調酒）

搜尋次數：21 次 WebSearch。WebFetch 對 wcc.coffee、iba-world.com、punchdrink.com 皆因網路限制無法連線，以下依據都是搜尋結果回傳的內容。

## 1. 修正清單

1. 「冷萃…低酸」→ 表格改「酸感低」，並補充：冷萃與熱沖 pH 相近（4.85 至 5.13），差別在熱沖可滴定酸較高，冷萃不代表比較不傷胃；Q1 答案同步補充。依據：https://pmc.ncbi.nlm.nih.gov/articles/PMC6207714
2. Q7「鹹味會抑制大腦對苦味的感知」→「鈉離子在味覺層面就會抑制苦味，且抑制苦味多於甜味」（後續研究指出作用在周邊味覺層面，而非認知層面）。依據：https://pubmed.ncbi.nlm.nih.gov/9177340/
3. Espresso Tonic「2000 年代…Koppi」→「2007 年 Koppi 放上菜單；也有說法指創辦人先在奧斯陸接觸到這個喝法」。依據：https://europeancoffeetrip.com/espressoandtonic-story/
4. 西西里咖啡「與 Mazagran（咖啡加檸檬）有淵源」→ Mazagran 原是源自阿爾及利亞的加糖冷咖啡，葡萄牙版才常加檸檬；兩者是否有直接淵源無可靠紀錄。依據：https://en.wikipedia.org/wiki/Mazagran_(drink)
5. Espresso Martini 故事：補上 Soho Brasserie、年份 1983 或 1985 兩說、客人故事無法證實、後來曾名 Pharmaceutical Stimulant、1990 年代末才以 Espresso Martini 之名流行。依據：https://www.diffordsguide.com/en-au/encyclopedia/1265/people/a-toast-to-dick-bradsell
6. Irish Coffee：補上「1940 年代初期（常見說法 1943 年）」，以及 1952 年是 Delaplane 與 Buena Vista 老闆 Jack Koeppler 一起重現（原文寫成 Delaplane 一人帶過去）。依據：https://flyingboatmuseum.com/irish-coffee-centre/more-about-chef-joe-sheridan/、https://kqed.org/news/11621844/the-true-history-of-irish-coffee-and-its-san-francisco-origins
7. 補充 IBA 標準配方作為對照（配方程式碼區塊未改）：Irish Coffee 威士忌 50ml / 熱咖啡 120ml / 鮮奶油 50ml / 糖 1 小匙；Espresso Martini 伏特加 50ml / 咖啡利口酒 30ml / 糖漿 10ml / 一份濃縮。依據：https://iba-world.com/irish-coffee/、https://iba-world.com/espresso-martini（僅透過搜尋摘要確認，無法直接開啟頁面）
8. Dalgona 原理「可溶性固體與糖形成黏稠溶液，能穩定包覆空氣」→「即溶咖啡的可溶性成分能包覆空氣，糖讓溶液變黏稠、減緩泡沫消散」（起泡來自即溶咖啡的界面活性成分，糖的角色是提高黏度）。依據：搜尋結果中的 foodcrumbles.com、sciencemeetsfood.org 說明（非一手來源，未列入參考資料）
9. Carajillo：補充 Licor 43 本身產自西班牙。依據：搜尋結果中的 Licor 43 Wikipedia 條目與 vinepair.com
10. 氮氣冷萃：補充常被提到的早期業者 Cuvee（2012）與 Stumptown（2013）。依據：https://cuveecoffee.com/blogs/news/the-origins-of-nitro-coffee
11. Toddy：補充「常見說法是 1964 年」、創辦人 Todd Simpson（另有 1963 年說法）。依據：https://www.toddycafe.com/the-toddy-story
12. WBC「創意飲品」補上英文名 signature beverage，並把「要求選手設計一杯能展現咖啡本身的飲品」改為「評審會看材料是否襯托並展現咖啡本身」，2026 年規則仍有此項目。依據：https://www.beanscenemag.com.au/sca-updates-rules-for-2026-world-barista-championship/

## 2. 查不到依據，已改成保守寫法

1. 氮氣冷萃「甜感錯覺」：找不到嚴謹的感官研究，只有業界說法（Starbucks、設備商）。改成「多被解釋為口感造成的錯覺，目前主要是業界說法；冷萃本身酸感較低也可能有關」，Q9 同步加註。
2. Espresso Martini 三顆咖啡豆「象徵健康、財富與快樂」：只有民間說法（另有其他解讀），改成「常見說法是象徵…」。
3. Dirty 咖啡名稱由來（「弄髒」杯壁）：查無可靠來源，改成「名稱常見的解釋是…」。
4. 京都冰滴與十七世紀荷蘭商人：原文已標「難以考證」，保留；查到的都是部落格，沒有一手史料。
5. 西西里咖啡：只能確認在台灣流行、與西西里關聯薄弱；原文「在台灣與中國流行」的「中國」部分查不到可靠來源，改成「台灣常見」。
6. Espresso Martini 客人要求的故事：改成「細節無法證實」。

## 3. 仍需作者確認
