## 1. 百年時間軸

| 時期 | 大事 |
| --- | --- |
| <b>1884 年</b> | 英商德記洋行（Tait & Co.）從馬尼拉引進約百株阿拉比卡咖啡苗，試種於今新北三峽一帶，是台灣最早的咖啡種植記錄，但並未持續 |
| <b>日治時期（1895–1945）</b> | 1902 年日本政府在今恆春熱帶植物園試種，證實阿拉比卡適合台灣。之後在雲林古坑荷苞山、花蓮瑞穗、台東、嘉義等地發展商業化種植，約 1942 年前後達到全盛，咖啡主要運往日本，傳說曾作為獻給天皇的貢品 |
| <b>戰後初期</b> | 日本市場消失，大部分咖啡園荒廢 |
| <b>1950–1960 年代</b> | 國際咖啡價格上漲，在美援與農業試驗機構支持下重新推廣（引進品種與後製技術），約 1960 年代初達到戰後高峰 |
| <b>冰河期（約 1960 年代中到 1990 年代）</b> | 巴西豐收使國際價格大跌、美援結束，政府對咖啡採取「不鼓勵、不限制、不輔導」，台灣咖啡沉寂近三十年 |
| <b>1999 年之後</b> | 921 大地震後，咖啡結合觀光休閒成為災後重建的選擇，雲林古坑以「台灣咖啡」品牌走紅，帶動各地重新種植 |
| <b>2015 年起</b> | 農糧署輔導產區縣市輪辦全國咖啡豆評鑑，縣市評鑑優勝者推薦參賽 |
| <b>2021 年</b> | 「典藏台灣精品咖啡國際競標」（Taiwan PCA）與國際卓越咖啡聯盟（ACE）合作舉辦，是台灣第一場精品生豆國際競標；同年「台農 1 號」取得品種權 |
| <b>2022 年</b> | 農糧署輔導成立「臺灣咖啡產業策略聯盟」；第二屆 PCA 中，阿里山「豆御香藝伎莊園」的藝妓以每磅 183 美元成交 |
| <b>2023 年</b> | 舉辦卓越盃示範競標，首次邀請國際評審依 COE 標準在台評選 |
| <b>2024 年</b> | <b>首屆臺灣卓越盃（Cup of Excellence Taiwan）</b>：台灣成為全球第 17 個、亞洲第 3 個舉辦 COE 的產地，有 4 支咖啡超過 90 分 |
| <b>2025 年</b> | 第二屆台灣 COE 舉辦，但經費爭議浮上檯面；農業部公布 2024 年全台咖啡種植面積達 1,216 公頃 |
| <b>2026 年 5 月</b> | 主辦單位宣布台灣 COE 停辦，原因是 ACE 年初起多次要求暫停計畫；主辦單位表示將另推新的國際賽事與競拍機制 |

台灣的<b>咖啡館文化</b>（日治時期的咖啡廳、戰後西門町老店、便利商店咖啡、精品咖啡館）見第 07 篇。

採收季大約在冬季到早春，依海拔而異。

## 4. 台灣咖啡的特色

### 品種

- 主要是阿拉比卡系：藝妓、SL34、黃波旁、紅波旁、鐵比卡等，也有農民自己選育的地方品系
- <b>台農 1 號</b>：農業部農業試驗所嘉義分所經約 15 年選育、從波旁系植株篩選而來的第一個本土咖啡品種，2021 年取得品種權。特點是適合中低海拔、耐候性佳、產量穩定，風味偏堅果香、溫和果酸、體脂感厚；低海拔生產也能達到精品等級。它的意義在於讓低海拔農民也能有競爭力，減少往高山開墾的壓力

### 風味

- 常被描述為清爽、甜感好、帶有「介於茶與咖啡之間」的特殊調性
- 有產業人士認為現行 SCA 評分表不完全能表達這種風味，正在發展更適合台灣咖啡的評測方式
- 負責咖啡研究與輔導的政府單位之一是茶及飲料作物改良場（前身為茶業改良場），這也反映了台灣咖啡與茶的淵源：適合高山茶的氣候與土壤，往往也適合咖啡，茶農的後製經驗也被帶入咖啡處理

### 產業型態：一條龍

- 台灣咖啡農常常自己種植、處理、烘焙、賣飲品，甚至經營觀光園區。很多農民具備杯測能力，這在世界各產區中相當少見
- 優點是反映品質的速度快、農民能保留大部分價值；缺點是規模小、產量分散，難以提供國際買家需要的批量

## 5. 挑戰

| 挑戰 | 說明 |
| --- | --- |
| <b>成本高</b> | 人工與土地成本遠高於主要產國，平價咖啡無法與進口豆競爭，只能走精品與在地體驗 |
| <b>產量小、不穩定</b> | 年產量不到進口量的零頭，且有大小年；國際競標需要數百公斤等級的單一批次，對小農來說是門檻 |
| <b>氣候變遷</b> | 暖化讓成熟期縮短、風味變薄；乾旱與颱風導致減產，例如 2023 年雲林古坑高海拔區因旱災造成大量不良果，經公告為災害救助區 |
| <b>水土保持</b> | 高海拔種植雖然品質好，但山坡地開墾涉及水土保持與法規；中低海拔品種的研發是解方之一 |
| <b>國際平台不穩</b> | COE 停辦暴露了國際賽事、經費來源與產業治理的問題：大型莊園可能仍有通路接觸國際買家，小農的曝光機會則受影響 |
| <b>標示與混豆</b> | 「台灣咖啡」有價差後，市場上曾有混入進口豆的疑慮，產地證明與追溯制度很重要 |

## 6. 評鑑與競標制度

| 層級 | 例子 | 作用 |
| --- | --- | --- |
| 縣市評鑑 | 嘉義縣生豆評鑑賽與阿里山莊園咖啡精英交流賽、雲林、台南、南投等地的地方評鑑 | 農民交流與年度品質檢驗，常搭配媒合會讓得獎豆直接賣給商家。例如 2022 年阿里山精英交流賽的特等獎以 52 萬元得標 |
| 全國評鑑 | 台灣國產精品咖啡豆全國評鑑 | 2015 年起由產區縣市輪辦，縣市賽優勝者推薦參賽 |
| 國際競標 | Taiwan PCA（2021、2022）、台灣 COE（2024、2025） | 讓國際買家以競標方式出價，建立國際價格與知名度 |

- 評鑑通常分為物理篩選（生豆瑕疵）、初賽、複賽、決賽，以 SCA 杯測方式評分，常依處理法分組（水洗、日曬、蜜處理，有時另設藝妓組）
- 評鑑制度很大程度推動了台灣咖啡的品質：農民為了賽事精進後製，也讓消費者有了選購的參考。但也要知道：比賽豆是金字塔頂端，市面上大多數台灣咖啡不是比賽等級，價格也不同

## 7. 消費端：台灣人怎麼喝咖啡

- <b>便利商店是最大通路之一</b>：九成咖啡族喝過 7-ELEVEN 咖啡，全家也接近四分之三。2000 年代起超商咖啡讓一杯現煮咖啡變成日常；近年超商更推出精品品牌與高價單品，例如 7-ELEVEN 的 CITY PRIMA，2023 年還曾推出一杯 800 元的阿里山藝伎咖啡
- <b>連鎖咖啡</b>：以門市數來看，2026 年前三大是星巴克（約 600 家）、路易莎（約 560 家）、85 度 C（近 400 家），競爭重點已從展店轉向品牌體驗、特殊場域與單店效率（第 11 篇有品飲練習）
- <b>獨立咖啡館與精品烘豆廠</b>：密度高、品質好，台灣咖啡師在國際賽事表現亮眼（例如 2016 年世界咖啡大師冠軍吳則霖）
- <b>趨勢</b>：市場兩極化。一端是平價、快速、外帶的日常咖啡，一端是高價精品與體驗；冰飲、甜飲與手搖飲的界線也越來越模糊

## 8. 尋訪台灣咖啡：實作指南

### 什麼時候去

- <b>冬季到早春</b>是採收與處理季，可以看到採果、去皮、曝曬；春季可能遇到咖啡開花（白色、帶茉莉般香氣）
- 各縣市評鑑後的媒合會與展銷活動，是一次喝到多支得獎豆的好機會

### 去哪裡

- 嘉義阿里山（高海拔得獎莊園集中）、雲林古坑（歷史與觀光）、台南東山 175 咖啡公路（小農密集）、南投、屏東、花東
- 拜訪莊園前先聯絡，採收季農民很忙，預約是基本禮貌

### 問什麼（可以拿來做小農訪談清單）

```txt
1. 品種：種了哪些？為什麼選這些？
2. 海拔與微氣候：日照、雲霧、遮蔭方式？
3. 田間管理：施肥、病蟲害、修剪怎麼做？
4. 採收：怎麼判斷熟度？分幾輪採？
5. 處理：用什麼處理法？發酵多久、怎麼控制？
6. 乾燥：曝曬場、棚架還是烘乾機？乾燥到多少含水率？
7. 產量與價格：一年產多少？生豆大概什麼價位？
8. 挑戰：這幾年最大的困難是什麼？
```

### 怎麼喝

- 用第 04 篇的杯測或第 05 篇的基準配方，把台灣豆與你的「基準豆」（衣索比亞水洗、巴西日曬）並排比較
- 同一個莊園不同處理法的豆並排喝，最能體會處理法的影響
- 留意屬於台灣的調性：茶感、溫和的酸、蜜糖般的甜

## 9. 未來走向

1. <b>精品化與規模化並行</b>：單一小農難以提供國際批量，產區開始嘗試「衛星莊園」等聯合模式，由有處理能力的莊園帶領周邊農戶統一品質、共同行銷
2. <b>本土品種與氣候調適</b>：台農 1 號之後，適合中低海拔、耐候的品種是研究重點；咖啡葉茶等副產品也為農民創造第二收入
3. <b>國際平台重建</b>：COE 停辦後，產業需要新的國際賽事與競拍機制，也需要更穩定的政府與民間合作
4. <b>風味語言的建立</b>：發展能表達台灣風土的評測與描述方式，就像台灣高山茶有自己的品茶語彙
5. <b>觀光與在地體驗</b>：台灣人喝得到最新鮮的國產咖啡、又能到產地拜訪，是進口咖啡無法取代的優勢

Q1 台灣最早的咖啡種植紀錄是什麼時候、由誰開始的？

1884 年由英商德記洋行從馬尼拉引進約百株阿拉比卡咖啡苗，在今新北三峽一帶試種，但並未持續。真正有計畫的商業種植要到日治時期才開始。
</toggle>

<toggle>
Q2 台灣咖啡為什麼會經歷近三十年的「冰河期」？又是什麼讓它復甦？

1960 年代巴西豐收使國際咖啡價格大跌，美援也結束，政府對咖啡採取「不鼓勵、不限制、不輔導」，加上經濟起飛後咖啡不再是重要經濟作物。1999 年 921 地震後，咖啡結合觀光成為災後重建的選擇，古坑以「台灣咖啡」走紅；之後又有消費市場成長、評鑑制度與國際競標推動精品化。
</toggle>

<toggle>
Q3 「台農 1 號」為什麼重要？

它是台灣第一個本土選育的咖啡品種，2021 年取得品種權。適合中低海拔、耐候、產量穩定，低海拔生產也能達到精品等級，讓低海拔農民有競爭力，也減少往高山開墾的水土保持壓力，並有助於因應氣候變遷。
</toggle>

<toggle>
Q4 台灣咖啡的自給率大約多少？這代表什麼？

國產年產量約九百到一千公噸，進口量約四萬公噸，自給率只有約 2 到 3%。代表台灣咖啡無法以量取勝，定位必然是精品、在地新鮮與產地體驗，而不是取代進口商品豆。
</toggle>

<toggle>
Q5 台灣咖啡產業「一條龍」的模式有什麼優缺點？

優點：農民從種植到烘焙、販售都自己做，很多人會杯測，品質回饋快，也能保留更多價值。缺點：規模小、產量分散，品質標準不一，難以滿足國際買家與競標對單一批次數量的要求。
</toggle>

<toggle>
Q6 2024 年首屆台灣 COE 有什麼意義？為什麼 2026 年停辦值得關注？

台灣成為全球第 17 個、亞洲第 3 個舉辦 COE 的產地，且有 4 支咖啡超過 90 分，代表國際評審與買家的肯定。停辦則讓台灣少了一個對國際曝光與定價的平台，特別影響缺乏國際通路的小農，也讓產業重新思考經費、治理與政府角色。
</toggle>

<toggle>
Q7 想去尋訪台灣咖啡，你會選什麼季節？拜訪小農時會問哪些問題？

冬季到早春的採收與處理季，可以看到採果、處理與曝曬（記得先預約）。問題可以涵蓋品種選擇、海拔與微氣候、田間管理、採收熟度判斷、處理與發酵控制、乾燥方式與含水率、產量與價格，以及最近的挑戰。
</toggle>

<toggle>
Q8 為什麼台灣的咖啡與茶關係密切？

適合高山茶的氣候、海拔與土壤也適合阿拉比卡；茶農的後製經驗被帶進咖啡處理；政府中負責咖啡研究輔導的單位之一也是由茶業改良場轉型而來。風味上，台灣咖啡常被形容帶有介於茶與咖啡之間的調性。
</toggle>

<toggle>
Q9 如果要你為台灣咖啡的未來提一個建議，你會提什麼？為什麼？

開放題。參考方向：用衛星莊園或合作社模式建立穩定批量；建立產地追溯與認證，避免混豆損害品牌；發展台灣專屬的風味描述；結合觀光與教育，讓消費者願意為在地新鮮付費；重建穩定的國際競標平台。重點是說明你的建議解決了哪一個挑戰。
</toggle>
